# Bank Marketing – Exploratory Data Analysis and Deep Learning

Project Overview
This project explores the Bank Marketing dataset using Python, data cleaning, exploratory data analysis (EDA), visualization, and a deep learning model.

Objectives
- Clean and preprocess the dataset.
- Analyze customer and campaign information.
- Create visualizations to identify patterns.
- Train and evaluate a deep learning model.

 Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- TensorFlow / Keras

 Dataset
UCI Bank Marketing Dataset:  
https://archive.ics.uci.edu/dataset/222/bank+marketing

 Project Files
- Bank_Marketing_EDA.ipynb – Complete code and analysis.
- bank_marketing_results.zip – Generated charts, model, and results.

 How to Run
1. Open Bank_Marketing_EDA.ipynb in Google Colab.
2. Run the notebook cells in order.
3. Review the generated visualizations and model evaluation results.

 Results
Model performance metrics and visualizations are included in the project output files.
